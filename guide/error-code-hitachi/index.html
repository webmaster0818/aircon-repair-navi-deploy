症状別ガイド

日立エアコン（白くまくん）のエラーコード・ランプ点滅の意味
回数別一覧と公式の修理料金

エアコン修理ナビ編集部|最終更新：2026年11月22日

日立のルームエアコン「白くまくん」は、不具合を主にランプの点滅回数でお知らせします。タイマーランプの点滅は室内機、みはりランプの点滅は室外機の異常のお知らせです（取扱説明書）。 本記事では、日立公式FAQ（kadenfan.hitachi.co.jp）と公式の修理料金表に掲載されている点滅回数ごとの内容を一覧にし、故障ではない点滅との見分け方、修理を依頼する場合の費用の目安をまとめています（2026年11月22日確認）。

結論：点滅を確認した場合の手順（公式の案内）

  1. どのランプが何回点滅しているかをメモします（「音声おしえて」ボタンがある機種はボタンで確認できます）。
  2. 電源プラグを抜くかブレーカーを切り、約3分後に入れ直して運転します。
  3. それでも点滅する場合は使用を中止し、販売店または日立の修理窓口に、メモした回数を伝えて点検を依頼します。

その他のランプ表示で異常を知らせるもの

  • すべてのランプが点滅：据え付けに問題が発生している可能性があり、販売店または取付工事業者への相談が案内されています。
  • 運転ランプとタイマーランプが交互に点灯：シーズン前自動点検の結果、室内機・室外機にトラブルが生じている可能性があります。
  • 洗浄ランプが4秒点灯・3秒消灯：室内機のファン掃除ユニットが異常のため停止しています。
  • クリーンランプが4秒点灯・1秒消灯：エアフィルターなどの部品が正しく取り付けられていない可能性があります。付け直しても点滅する場合は、フィルター掃除ユニットの異常による停止です。
  • ecoランプのみ点滅：「見る・聞く・感じるセンサー」部の不具合です。
  • 遠隔ランプが5回点滅を繰り返す：無線LAN機能が正常に動作していません。

※出典：日立公式FAQ（kadenfan.hitachi.co.jp/support/ra/q_a/a33.html・post-141.html）。2026年11月22日確認。表示は機種により異なります。

日立に修理を依頼した場合の料金の目安

日立公式の修理料金の目安は、技術料・部品代・出張料の合計です。出張料は3,850円（税込）、見積後にキャンセルした場合や点検・説明だけで終わった場合は診断料と出張料の合計5,830円（税込）がかかります。 点滅回数から想定される主な部品の修理料金は次のとおりです（室内機は通常設置・室外機は平地置きの場合）。

修理内容（交換部品）公式の目安（税込・出張料等を含む）
室内メインキバン40,000〜45,000円前後
室外キバン40,000〜55,000円前後
室外ファンモーター39,000〜54,000円前後

※出典：日立公式「ルームエアコン 修理料金の目安」（kadenfan.hitachi.co.jp/support/repair/raj.html）、「出張修理のご依頼」（kadenfan.hitachi.co.jp/support/inquiry/repair/housecall.html）。2026年11月22日確認。日立へ直接依頼した家庭用の修理の目安で、高所設置などは別料金です。販売店経由の料金は販売店にご確認ください。保証期間はお買い上げの日から1年間です。

コンプレッサーの交換は10万円を超えるため、製造から10年前後の機種では買い替えもあわせてご検討ください。判断の目安は修理と買い替えの比較、メーカー各社の料金はメーカー修理費用の比較でご覧いただけます。 メーカー以外の修理業者に相談したい場合は、エアコン修理業者ランキングで料金と対応エリアを比較できます。

よくある質問

Q1. 日立エアコンのタイマーランプが点滅しています。故障でしょうか？
日立公式FAQでは、タイマーランプの点滅は「本体に異常が発生している可能性があります」とされ、使用を中止して販売店または修理相談窓口に点検を相談するよう案内されています。取扱説明書では、電源プラグを抜くかブレーカーを切り、約3分後に入れ直して運転し、それでも点滅する場合は販売店へ連絡する手順が示されています。点滅が消えても一時的な改善の場合があると公式に注記されています（2026年11月22日確認）。
Q2. 点滅の回数はどのように数えればよいですか？
日立公式FAQでは、リモコンに「音声おしえて」ボタンがある製品は、ボタンを押すとタイマーランプの点滅回数を確認できると案内されています。ボタンがない機種は、点滅と消灯の繰り返しを目視で数えてメモしてください。ランプ表示は機種によって異なると公式に注記されています。
Q3. 暖房中に運転ランプが点いたり暗くなったりします。
日立公式FAQでは、暖房時に運転ランプが点灯と減光を繰り返すのは、予熱運転（2〜3分）または室外機の霜取り運転（5〜22分）中であり、故障ではないとされています。ただし、25分以上経過しても続く場合は点検を勧めています（2026年11月22日確認）。
Q4. 日立に修理を依頼すると、点検だけでも費用はかかりますか？
日立公式の修理料金のページでは、出張料は3,850円（税込）、見積後にキャンセルした場合は診断料と出張料の合計5,830円（税込）とされています。修理を伴わない点検・説明だけで終わった場合も5,830円です。販売店経由で依頼した場合の料金は販売店にご確認ください（2026年11月22日確認）。
Q5. みはりランプが点灯したままです。異常でしょうか？
日立公式FAQでは、みはりランプの点灯（点滅ではない状態）は故障ではないとされています。異常のお知らせは点滅です。タイマーランプが点灯し続けている場合も、公式では故障ではないと案内されています。
