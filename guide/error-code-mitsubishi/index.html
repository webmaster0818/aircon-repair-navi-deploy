三菱エアコン(霧ヶ峰)のランプ点滅・エラー表示
表示ごとの意味と対処【家庭用】

エアコン修理ナビ編集部|最終更新：2026年9月17日

三菱電機の家庭用ルームエアコン(霧ヶ峰)は、不具合や操作待ちをランプの点滅パターンと一部の表示(数字・FL・U1など)で知らせます。 ダイキンのような消費者向けエラーコード一覧は公開されていないため、本記事では三菱電機の消費者向け公式FAQ（2026年9月17日確認）にもとづき、 表示ごとの意味、ご自身でできる対処、修理を依頼する判断の基準をご説明します。

「点検コード検索」は販売店向けサービスです

数字の点検コードを検索できる三菱電機の「WIN2K 点検コード検索」は、公式に「販売店様向けのサービスです。個人のお客様は分解・修理などはせずに、必ずお買上げの販売店、または三菱電機 修理窓口へご相談ください」と明記されています(2026年9月17日確認)。 公式の案内では、数字が点滅した場合は意味を調べてご自身で修理しようとせず、下の表の安全な確認のみを行ったうえで点検を依頼するよう求めています。

表示されることが多い2つのパターンの対処手順

全ランプ点滅(FL表示)：お手入れ後に多い表示

掃除のために上下風向フラップを外した後、フラップが正しく取り付けられていないと、全ランプが点滅して運転できなくなります。公式FAQでは「故障ではありません」と明記されており、ストッパーを確実に取り付け直すことで復帰します（取付け方は機種により異なるため、取扱説明書をご参照ください）。修理を依頼する前に、まずこの点をご確認ください。

数字点滅・運転ランプ点滅：3つの手順による切り分け

①フラップの取付を確認します → ②室外機の吹出口・吸込口まわりの物を撤去します → ③電源プラグを抜いて約1分後に差し直し、再運転します。 この3つの手順で解消しない場合は、公式FAQによると「制御機器や部品の訪問修理が必要な故障」です。点滅している数字を控えたうえで、修理の依頼先のガイドを参考に依頼先をお選びください。

修理を依頼する前の費用の確認

三菱電機は訪問診断後にキャンセルした場合でも5,390円（当サイト調査値）がかかるため、依頼前に費用の目安を確認しておくことをおすすめします。メーカー修理費用の比較・修理費用の相場・27社の料金インデックスをご覧ください。 製造から10年前後の機種は寿命と買い替えの判断もあわせてご覧ください。

よくある質問

Q1. 霧ヶ峰には、ダイキンのようなエラーコード一覧はありますか？
三菱電機の家庭用ルームエアコンは、「ランプの点滅パターン」と一部の表示（数字点滅・FL・U1など）で不具合を知らせる方式であり、消費者向けのエラーコード一覧は公開されていません。数字コードを検索できる「点検コード検索(WIN2K)」はありますが、公式に「販売店様向けのサービスです。個人のお客様は分解・修理などはせずに、必ずお買上げの販売店、または三菱電機 修理窓口へご相談ください」と明記されています(2026年9月17日確認)。本記事は、消費者向け公式FAQの公表内容のみにもとづいて作成しています。
Q2. すべてのランプが点滅して動かない場合は故障ですか？
多くの場合、故障ではありません。三菱電機公式FAQでは「上下風向フラップが正しく取り付けられていないと、すべてのランプが点滅して、運転できません。故障ではありませんので、すべての上下風向フラップのストッパーを確実に取付けてください」と案内されています（FAQ No.2646・2026年9月17日確認）。お手入れでフラップを外した後に表示されやすい症状です。体感温度モニター搭載機では「FL」表示を伴います(FAQ No.2645)。
Q3. 室内機に数字が点滅している場合はどうすればよいですか？
三菱電機公式FAQ（No.2619）では「室内機または室外機に異常が起きていることが考えられます」としたうえで、①室外機の吹出口・吸込口周囲をふさぐ物を取り除く、②電源プラグを抜いて約1分待ち、差し直して再運転する、の2点が案内されています。それでも点滅が解消しない場合は本体の不具合の可能性があるため、電源プラグを抜いて、販売店または三菱電機修理窓口へ点検・修理をご依頼ください。その際は「点滅している数字を伝える」よう公式に案内されています（2026年9月17日確認）。
Q4. 点滅が解消しない場合の修理費用はどのくらいですか？
修理内容により異なりますが、当サイトが調査したメーカー修理の目安では、三菱電機は訪問診断後にキャンセルした場合でも5,390円（当サイト調査値・確認日は費用ガイドをご参照ください）がかかります。症状別の概算は、メーカー修理費用の比較ページと修理費用相場のガイドに掲載しています。製造から10年前後の機種は部品保有期間の影響もあるため、寿命と買い替え判断のガイドもあわせてご参照ください。
Q5. 他メーカーのエラーコードも確認できますか？
ダイキンは家庭用の公式エラーコード検索を公開しており、当サイトでは主要16コードの早見表を掲載しています（ダイキンのエラーコード一覧ガイド）。パナソニックは、当サイトから公式FAQの内容を確認できないため、公式サポートページを直接ご確認ください。切り分けの一般的な手順は、症状別ページ（エラーコードが出る）でご説明しています。
