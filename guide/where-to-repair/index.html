エアコン修理はどこに頼む？
メーカー・量販店・修理業者の使い分け

エアコン修理ナビ編集部|最終更新：2026年8月10日

エアコンが故障したとき、メーカー・購入した量販店・修理業者のどこに頼むかで、費用も日数も大きく変わります。 順番を間違えると「保証で無料だったのに有償で直してしまった」という損も起こりがちです。 この記事では、損しない依頼先の決め方を3ステップのフローチャートで解説します（保証・窓口情報は各社公式サイトを2026年8月10日に確認）。

結論：3つの質問で依頼先が決まる

依頼先選びは、「賃貸か」「保証が残っているか」「急ぎか」の3つで決まります。 賃貸の備え付けエアコンならまず管理会社（費用負担の解説はこちら）。 持ち家・自己所有なら、保証→購入店→修理業者の順で確認するのが損しない順番です。

依頼先フローチャート

Q1. 賃貸の備え付けエアコン？

YES → まず管理会社・大家さんへ連絡（原則大家負担）NO → 次へ

Q2. 購入から1年以内？（冷えない故障は5年以内も対象の可能性）

YES → メーカー保証で無償修理の可能性。メーカー窓口へNO → 次へ

Q3. 量販店の長期保証（5〜11年）に加入している？

YES → 購入した量販店の保証窓口へNO → 修理業者へ（即日対応も可能）

⚡ 例外：とにかく今日直したいとき

保証が残っていても、メーカー・量販店の訪問は繁忙期に日数がかかることがあります。「猛暑で待てない」場合は即日対応の修理業者への相談が現実的です（有償になる点は理解したうえで）。

①メーカーに頼むべきケース

購入から1年以内は本体のメーカー保証期間のため、まずメーカーへ。さらに重要なのが冷媒系統（冷媒回路）の5年保証です。 ダイキンは「ルームエアコン本体: 1年間／冷媒系統: 5年間」（冷媒系統＝現地配管を除く圧縮機、熱交換器および室内・室外ユニットの内配管）、 パナソニックも本体1年・冷媒循環回路部品5年と公式に案内しています。

💡 「冷えない」は5年保証の対象かも

ガス漏れ・コンプレッサー不良など「冷えない」系の故障は冷媒系統が原因のことがあり、購入5年以内なら無償修理になる可能性があります。有償の業者を呼ぶ前に、保証書と購入日を確認しましょう。

また、メーカーには補修用性能部品の保有期間があり、ダイキン・パナソニックとも エアコンは製造打切り後10年と公式に案内しています。 製造から10年を超えた機種は部品がなく修理できない場合があるため、買い替えとの比較も視野に入れてください。

②購入店（量販店）に頼むべきケース

量販店の長期保証に加入している場合は、メーカー保証が切れていても購入店経由で安く直せる可能性があります。 例えばヤマダデンキの無料長期保証は、税込33,000円以上のエアコンが対象で、4年間・6年間・11年間から選択する仕組みです（公式の保証規定では、3年目までは技術工料・部品代・出張料が保証され、4年目以降は技術工料のみ等の条件があります。加入は商品購入と同時に限られます）。

ケーズデンキ・ビックカメラ・ヨドバシカメラ・エディオンなど他の量販店にも長期保証制度がありますが、 年数・条件は各社異なります（各社公式サイトでご確認ください）。「どこで買ったか」を思い出し、レシート・保証書・会員アプリを確認するのが第一歩です。

関連レビュー: ヤマダデンキの出張修理 / ケーズデンキの修理

③修理業者に頼むべきケース

次のどれかに当てはまるなら、修理業者への依頼が現実的です。

  • 保証がすべて切れている（購入1年超・長期保証なし）
  • 今日・明日中に直したい（メーカーの訪問待ちが長い繁忙期）
  • メーカーに部品がなく修理を断られた（製造打切り後10年超）→ 買い替えも比較
  • 自分で設置した中古・譲り受け品で購入店ルートがない

修理業者は料金体系・対応スピードがさまざまです。国民生活センターが2026年6月に注意喚起したとおり、 ネット広告の「安い」「即日」だけで選ばず、作業前に総額見積もりを書面で確認しましょう。

よくある質問

Q1. エアコンが壊れたら、まずどこに連絡すればいいですか？
順番は①賃貸の備え付けなら管理会社・大家さん、②購入から1年以内（冷媒回路の故障は5年以内が目安）ならメーカー、③量販店の長期保証に入っているなら購入店、④どれにも当てはまらない・急ぎで直したいなら修理業者、です。保証が使えれば無料または安く直せる可能性があるため、有償の修理業者は保証の確認後に検討するのが損しない順番です。
Q2. メーカー保証は何年ですか？
ダイキン・パナソニックの公式情報では、エアコン本体の保証は購入から1年、冷媒系統（圧縮機・熱交換器など冷媒が循環する部分）は5年です。冷えない故障はガス漏れなど冷媒系統が原因のことがあり、購入5年以内なら無償修理の対象になる可能性があります。他メーカーも保証書に同様の区分があることが多いため、まず保証書を確認してください。
Q3. 量販店の長期保証とはどういうものですか？
例えばヤマダデンキの無料長期保証は、税込33,000円以上のエアコン購入時に加入でき、4年間・6年間・11年間から選択する仕組みです（3年目までは技術工料・部品代・出張料を保証、4年目以降は技術工料のみ等の条件があります）。購入時にしか加入できないため、故障してから入ることはできません。保証書やレシート、購入店の会員ページで加入状況を確認しましょう。
Q4. 製造から10年以上たったエアコンでも修理できますか？
ダイキン・パナソニックは補修用性能部品の保有期間を製造打切り後10年と公式に案内しています。これを過ぎると部品がなく修理自体ができない場合があります。10年超のエアコンは修理費と買い替え費用を比較して判断するのがおすすめです。当サイトの「修理と買い替えどっちが得？」で判断基準を解説しています。
Q5. とにかく今日中に直したい場合は？
メーカーや量販店の修理は受付から訪問まで日数がかかることがあり、特に7〜8月の繁忙期は1週間以上待つ場合もあります。即日対応をうたう修理業者に朝いちばんで連絡し、症状と総額見積もりを確認したうえで依頼するのが現実的です。当サイトの即日対応ランキングで受付24時間の業者を比較できます。

まとめ・出典

  • 順番は賃貸→管理会社／保証内→メーカー／長期保証→購入店／それ以外・急ぎ→修理業者
  • 本体1年でも冷媒系統は5年保証（ダイキン・パナソニック公式）——「冷えない」は要確認
  • 部品保有は製造打切り後10年——10年超は買い替えと比較
  • 修理業者は総額の書面見積もりを確認してから依頼
