エアコンの異音「ガガガ」など
症状別の原因と対処【2026年】

エアコンから「ガガガ」「カラカラ」「ポコポコ」「キーン」といった異音は、種類によって考えられる原因が異なり、清掃で解消する軽度のものから、内部部品の不具合まで幅があります。本記事では、音の種類別の原因、ご自身でできる確認・対処、業者へ依頼すべき症状をご説明します。

エアコンの異音が示す状態

エアコンの異音は、ホコリや異物の付着といった軽度の原因による場合もあれば、ファンやモーターなど内部部品の劣化・不具合を示している場合もあります。まず音の種類と、鳴る時間帯や状況（運転開始時のみか、常時か）を把握することが、原因を絞り込む手がかりになります。

清掃や設定の見直しで収まる音もありますが、改善しない場合や他の異常を伴う場合は、専門業者へ点検を依頼することをおすすめします。

音の種類別の原因と対処

「ガガガ / ガタガタ」という音

考えられる原因
ファンへの異物の接触、ファンの軸ずれやモーターの劣化、室外機の固定のゆるみなどが考えられます。何かが接触している音であることが多くあります。
ご自身でできる確認
運転を止め、フィルターや吹き出し口に異物・ホコリの塊がないかを確認します。室外機が傾いていないか、周囲の物が当たっていないかもあわせて確認します。
業者へ依頼すべき症状
異物が見当たらないのに鳴り続ける場合や、振動が大きい場合は、内部部品の不具合の可能性があるため、業者へご依頼ください。

「カラカラ / カタカタ」という音

考えられる原因
ファンに付着したゴミや、内部の小さな部品・ネジのゆるみ、ルーバー（風向き板）の干渉などが原因である場合があります。
ご自身でできる確認
フィルター清掃と吹き出し口の確認を行います。ルーバーが何かに引っかかっていないかもご確認ください。
業者へ依頼すべき症状
清掃しても改善しない場合や、金属がこすれるような音が続く場合は、点検をご依頼ください。

「ポコポコ / ボコボコ」という音

考えられる原因
気密性の高い部屋で、ドレンホースから外気が逆流して発生することが多い音です。故障ではない場合もありますが、排水の不具合が原因となっている場合もあります。
ご自身でできる確認
換気扇を止める、窓を少し開けて気圧差を緩和するといった方法で収まる場合があります。ドレンホースの先端に逆流防止の部材を取り付ける方法もあります。
業者へ依頼すべき症状
水漏れを伴う場合や、排水が正常に行われていない様子がある場合は、ドレン関連の点検をご依頼ください。

「キーン / ピーといった高い音」という音

考えられる原因
電子部品やインバーターに由来する高周波音の場合もあれば、内部部品の異常が原因の場合もあります。運転開始直後のみ鳴る場合は、正常な範囲であることもあります。
ご自身でできる確認
一度電源を切り、数分後に再運転して再現するかを確認します。常に鳴る場合や音が大きくなる場合は、その状況を記録してください。
業者へ依頼すべき症状
音が大きくなる、焦げ臭いなど他の異常を伴う場合は、すぐに運転を止めて業者へご相談ください。

ご自身でできる確認・対処

業者へ依頼する前に、取扱説明書の範囲で確認を行っておくと、原因の切り分けや相談が円滑になります。

  • ・運転を止め、電源を切ってからフィルターを外して清掃します。
  • ・吹き出し口やルーバーに異物・ホコリの塊がないか、目視で確認します。
  • ・室外機が傾いていないか、周囲に物が当たっていないかを確認します。
  • ・音が鳴る時間帯と音の種類を記録します（業者への説明に役立ちます）。

業者へ依頼すべき症状

  • ・清掃・確認をしても異音が改善しない場合
  • ・金属がこすれる音や大きな振動を伴う場合
  • ・異音とあわせて水漏れ・冷えない・効かないなどの症状がある場合
  • ・焦げ臭い・煙・火花など、すぐに対応すべき異常がある場合

これらに当てはまる場合は、使用を続けず、専門業者に点検・修理をご依頼ください。異音の症状ページもあわせてご確認いただくと、対応する業者を探しやすくなります。

安全上の注意

  • ・内部を無理に分解しないでください（感電・けが・故障悪化・保証外の原因になります）。
  • ・清掃や確認の際は、必ず電源を切ってから行ってください。
  • ・焦げ臭い・煙が出るなどの場合は、すぐに運転を止めて使用をお控えください。
  • ・高所での作業は行わず、専門業者にご依頼ください。

よくある質問

Q.エアコンの「ガガガ」という音は故障によるものですか？

必ずしも故障とは限りません。フィルターや吹き出し口にホコリの塊や異物が当たっているだけの場合もあり、清掃で改善することがあります。一方で、ファンの軸ずれやモーターの劣化など内部部品の不具合が原因のこともあります。清掃しても改善しない場合や、振動が大きい場合は、専門業者に点検をご依頼ください。

Q.異音がする状態で使い続けても問題ありませんか？

焦げ臭いにおい、煙、火花、急な異音の悪化、運転停止などを伴う場合は、すぐに運転を止めて使用をお控えください。それ以外でも、異音が続く場合は内部で部品が干渉・劣化している可能性があるため、早めに点検を受けることをおすすめします。

Q.自分で分解して直してもよいですか？

おすすめしません。エアコンは電気・冷媒を扱う機器であり、無理な分解は感電・けが・故障の悪化や保証対象外となる原因になります。ご自身で行う作業はフィルター清掃や吹き出し口の目視確認など、取扱説明書の範囲にとどめ、内部の修理は専門業者へご依頼ください。

Q.ポコポコという音は放っておいても問題ありませんか？

気密性の高い部屋でドレンホースから外気が逆流して発生する場合は、故障ではないことが多くあります。換気の調整や逆流防止部材で軽減できる場合があります。ただし、水漏れを伴う場合は排水の不具合が考えられるため、点検をご依頼ください。

Q.修理費用はどのくらいかかりますか？

原因や交換部品によって幅があります。ファン系の修理は8,000〜40,000円程度、内部部品の交換が必要な場合はさらに高くなることもあります。これらは一般的な目安であり、実際の金額は機種・症状・業者によって異なるため、見積もりでご確認ください。費用の詳細は費用ガイドもご覧ください。

まとめ

エアコンの異音は、音の種類によって原因がさまざまです。「ガガガ」「カラカラ」はファンや異物、「ポコポコ」はドレンの逆流、「キーン」は電子部品由来などが考えられます。まずはフィルター清掃や目視確認といった安全な範囲で対処し、改善しない場合や他の異常を伴う場合は、専門業者に点検をご依頼ください。
