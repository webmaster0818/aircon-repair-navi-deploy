富士通（ゼネラル）エアコンのエラーコード・ランプ点滅の意味
点滅回数の一覧と修理の受付窓口

エアコン修理ナビ編集部|最終更新：2026年11月24日

富士通ゼネラルのエアコン「ノクリア」は、異常を検知すると運転ランプとタイマーランプの点滅回数でお知らせします。 富士通ゼネラルは2026年1月1日に社名を「株式会社ゼネラル」に変更しており、点滅の意味は同社公式サイトの「自己診断早見表」で確認できます。 本記事では、早見表のうち2011年度以降に生産された機種の内容と、形名から生産年度を調べる方法、修理を依頼する場合の窓口をまとめています（2026年11月24日確認）。

結論：ランプが点滅した場合の手順（公式の案内）

  1. 運転ランプとタイマーランプが、それぞれ何回点滅しているかを数えます（13秒で1サイクル）。
  2. 形名（室内機の銘板または保証書に記載）から生産年度を調べ、下の早見表で内容を確認します。
  3. 点検・修理が必要な表示であれば、運転を停止して電源プラグを抜き、販売店またはゼネラルコールセンターに形名と点滅の状態を伝えます。

形名から生産年度を調べる方法

ゼネラルの早見表は生産年度によって内容が異なります。形名（機種名）の数字2桁の次にある文字（アルファベットまたは数字）が生産年度を表します。数字が3桁以上続く場合は、数字の最後の桁が生産年度です。 アルファベットと数字は10年前後で同じ文字が再び使われるため（例：Tは2026年度と2008年度）、購入時期とあわせてご確認ください。

運転ランプとタイマーランプが同時に連続点滅試運転表示（リモコンの「運転/停止」で一度停止し、再度運転します）

※出典：ゼネラル公式「自己診断早見表」「室内機のランプが点滅する」（generalww.com/jp/support/faq/as/0084/）。2026年11月24日確認。ダストボックスのランプが1秒点灯・1秒消灯で点滅している場合は、ダストボックスの取り付けを確認し、改善しなければ点検が必要とされています。2004年度以前の生産品は、霜取り中に運転ランプが通常の点滅をする場合があります。

よくある質問

Q1. 富士通のエアコンのサポートはどこで調べればよいですか？
株式会社富士通ゼネラルは2026年1月1日に社名を「株式会社ゼネラル」に変更しており、エアコン「ノクリア」のサポート情報はゼネラルの公式サイト（generalww.com）に掲載されています。旧サイト（fujitsu-general.com）のサポートページにアクセスすると、ゼネラルの公式サイトに転送されます（2026年11月24日確認）。
Q2. 運転ランプとタイマーランプが交互に点滅しています。故障ですか？
ゼネラル公式の自己診断早見表では、運転ランプとタイマーランプの連続した交互点滅は「停電復帰」の表示とされています。停電や電源プラグの抜き差しで一度電源が切れたときに表示されるもので、故障ではありません。同時点滅の場合は「試運転表示」です。
Q3. 点滅の回数はどのように数えればよいですか？
公式の早見表では、運転ランプとタイマーランプの点滅回数をランプごとに数えるよう案内されています。2005年度生産以降の一部を除いた機種では、ランプの点滅は13秒で1サイクルです。回数を数えたら、運転を停止して電源プラグを抜き、形名と点滅の状態を販売店またはコールセンターに伝えます。
Q4. メーカー保証は何年ですか？
ゼネラル公式の「よくあるご質問」では、エアコンのメーカー保証期間は、冷媒回路（圧縮機・冷却器・本体付属配管など）がお買い上げ日から5年間、本体（消耗品を除く）がお買い上げ日から1年間とされています。補修用性能部品の保有期間は製造打ち切り後10年間です（2026年11月24日確認）。
